🚀 QUICK START (3 STEPS)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1️⃣  CONFIGURE AIRTABLE
   Edit .env file with your credentials:
   
   $ nano .env
   
   Set these values:
   - AIRTABLE_API_KEY=your_key_here
   - AIRTABLE_BASE_ID=your_base_id
   - AIRTABLE_TABLE_NAME=Tracks

2️⃣  TEST YOUR SETUP
   
   $ python -m src.cli config
   
   This will show your current configuration.

3️⃣  GENERATE YOUR FIRST VIDEO
   
   $ python -m src.cli generate --record-id recXXXXXXXXXXXXXX
   
   Replace recXXXXXXXXXXXXXX with an actual record ID from Airtable.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
💡 COMMON USE CASES
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

🎯 USE CASE 1: Generate from Airtable Record
   
   When you have a track in Airtable and want to create karaoke:
   
   $ python -m src.cli generate --record-id recABC123XYZ456

🎯 USE CASE 2: Batch Generate Pop Songs
   
   Generate karaoke for all Pop songs:
   
   $ python -m src.cli batch --genre Pop

🎯 USE CASE 3: Wedding Songs from 2000s
   
   Filter by multiple criteria:
   
   $ python -m src.cli batch --event-type Wedding --decade 2000s

🎯 USE CASE 4: Preview Before Processing
   
   See what would be generated without actually doing it:
   
   $ python -m src.cli batch --genre Rock --dry-run

🎯 USE CASE 5: API Integration
   
   Start the API server:
   
   $ ./run_api.sh
   
   Then call from Airtable automation or script:
   
   curl -X POST "http://localhost:8000/generate" \
     -H "Content-Type: application/json" \
     -d '{"record_id": "recXXXXXXXXXXXXXX"}'

🎬 WORKFLOW EXAMPLES

WORKFLOW 1: Manual Single Generation
1. Find record ID in Airtable
2. Run: python -m src.cli generate --record-id <ID>
3. Check output/ directory for video

WORKFLOW 2: Automated Batch Processing
1. Set up filters (genre, event type, decade)
2. Run: python -m src.cli batch --genre Pop --max-records 10
3. Videos are generated and paths saved to Airtable

WORKFLOW 3: API Integration with Airtable
1. Start API: ./run_api.sh
2. Create Airtable automation
3. Automation calls API when new record is created
4. Karaoke video generated automatically

WORKFLOW 4: Scheduled Batch Jobs
1. Create a cron job or scheduled task
2. Run batch command with filters
3. Process new tracks automatically

• Ensure you have enough disk space in the output/ directory
• The .env file contains sensitive credentials - never commit it to Git
• Generated videos are saved locally - consider cloud storage for production
• FFmpeg must be installed and accessible in your PATH
